from phasic import Graph

def coalescent(state):
    transitions = []
    for i in range(state.size):
        for j in range(i, state.size):            
            same = int(i == j)
            if same and state[i] < 2:
                continue
            if not same and (state[i] < 1 or state[j] < 1):
                continue 
            new = state.copy()
            new[i] -= 1
            new[j] -= 1
            new[i+j+1] += 1
            rate = state[i]*(state[j]-same)/(1+same)
            transitions.append((new, rate))
    return transitions

nr_samples = 4
initial_state = [nr_samples]+[0]*(nr_samples-1)
graph = Graph(coalescent, ipv=initial_state)
graph.moments(10)

Multivariate Phase-Type Distributions

Multivariate phase-type distributions assign a vector of rewards to each state, resulting in a vector-valued outcome:

\[ \boldsymbol{Y} \sim MPH^*(\boldsymbol{\alpha}, \boldsymbol{S}, \boldsymbol{R}) \]

where \(\boldsymbol{R}\) is a matrix of rewards (each row corresponds to a state, each column to a reward dimension).

Cross moments

The covariance between marginal reward dimensions \(i\) and \(j\):

\[ \begin{align*} \text{Cov}(Y_i, Y_j) =& \boldsymbol{\alpha}\boldsymbol{U}(\boldsymbol{R}_{\cdot i})\boldsymbol{U}(\boldsymbol{R}_{\cdot j})\mathbf{e} \\ &+ \boldsymbol{\alpha}\boldsymbol{U}(\boldsymbol{R}_{\cdot j})\boldsymbol{U}(\boldsymbol{R}_{\cdot i})\mathbf{e} \\ &- \boldsymbol{\alpha}\boldsymbol{U}(\boldsymbol{R}_{\cdot i})\mathbf{e} \cdot \boldsymbol{\alpha}\boldsymbol{U}(\boldsymbol{R}_{\cdot j})\mathbf{e} \end{align*} \]

Daisy chaining moment computation

k’th moment: \(\mathbb{E}[\tau^k]=k!\boldsymbol{\alpha} (\boldsymbol{U}\triangle(\boldsymbol{r}))^{k}\mathbf{e}\). Assume unit rewards for simplicity.

First moment:

\[ \mathbb{E}[\tau] = \boldsymbol{\alpha} \boldsymbol{U}\triangle(\boldsymbol{r})\mathbf{e} \]

Second moment:

\[ \mathbb{E}[\tau^2] = 2\cdot\boldsymbol{\alpha} \boldsymbol{U}\triangle(\boldsymbol{r})\boldsymbol{U}\triangle(\boldsymbol{r})\mathbf{e} = 2\cdot\boldsymbol{\alpha} \boldsymbol{U}\!\triangle\!\,(\boldsymbol{r'}) \mathbf{e} \]

where

\[ \triangle\!\,(\boldsymbol{r'}) \mathbf{e} = \boldsymbol{r'} =\boldsymbol{U}\mathbf{e} \]

where \(\boldsymbol{r'}\) are the waiting times (Green’s matrix row sums) computed for the first moment.
