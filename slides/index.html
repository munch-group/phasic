  • “Distribution of time to absorption of a discrete space Markov jump process.”

Marginal moments

\(k\)-th moment of the reward-transformed distribution:

\[\mathbb{E}[Y^k] = k! \boldsymbol{\alpha} (\boldsymbol{U} \boldsymbol{\Delta}(\boldsymbol{r}))^k \mathbf{e}\]

where \(\boldsymbol{\Delta}(\boldsymbol{r})\) is a diagonal matrix with rewards on the diagonal.

Multivariate Phase-Type Distributions

Multivariate phase-type distributions assign a vector of rewards to each state, resulting in a vector-valued outcome:

\[\boldsymbol{Y} \sim MPH^*(\boldsymbol{\alpha}, \boldsymbol{S}, \boldsymbol{R})\]

where \(\boldsymbol{R}\) is a matrix of rewards (each row corresponds to a state, each column to a reward dimension).

Advantages of Graph Representation

Sparsely connected state spaces:

  • Memory efficiency:
    • Store only existing transitions (not full \(p \times p\) matrix)
  • Computational efficiency: Operations on edges only
    • Many algorithms: \(O(|V|^2)\) vs \(O(p^3)\) for matrix operations
  • Iterative construction: Build state space incrementally
    • Add vertices and edges as needed
    • Natural for complex phenomena
  • Intuitive modeling: Specify transitions from each state independently
    • Markov property: next state depends only on current state
    • Easy to encode complex models
  • Big O notation for algorithms

As var as the interaction between two adjacent epochs, it does not matter if the former epoch comprise multiple epoch or not. So for starters we just need to consider a two epoch model.

from phasic import Graph

def coalescent(state):
    transitions = []
    for i in range(state.size):
        for j in range(i, state.size):            
            same = int(i == j)
            if same and state[i] < 2:
                continue
            if not same and (state[i] < 1 or state[j] < 1):
                continue 
            new = state.copy()
            new[i] -= 1
            new[j] -= 1
            new[i+j+1] += 1
            rate = state[i]*(state[j]-same)/(1+same)
            transitions.append((new, rate))
    return transitions

nr_samples = 4
initial_state = [nr_samples]+[0]*(nr_samples-1)
graph = Graph(coalescent, ipv=initial_state)
#graph.plot()
graph.expectation()

Higher-order moments

The variance

\[\text{Var}(\tau) = 2\boldsymbol{\alpha} \boldsymbol{U}^2 \mathbf{e} - (\boldsymbol{\alpha} \boldsymbol{U} \mathbf{e})^2\]

Higher-order moments

k’th moment: \(\mathbb{E}[\tau^k]=k!\boldsymbol{\alpha} (\boldsymbol{U}\triangle(\boldsymbol{r}))^{k}\mathbf{e}\)

Expectation: \(\mathbb{E}[\tau] = \boldsymbol{\alpha} \boldsymbol{U}\triangle(\boldsymbol{r})\mathbf{e}\)

2’nd moment: \(\mathbb{E}[\tau^2] = 2\cdot\boldsymbol{\alpha} \boldsymbol{U}\triangle(\boldsymbol{r})\boldsymbol{U}\triangle(\boldsymbol{r})\mathbf{e}\)

\(\mathbb{E}[\tau] = \boldsymbol{\alpha} \boldsymbol{U}\! \triangle\!\,(\boldsymbol{r}) \mathbf{e} = \boldsymbol{\alpha} \boldsymbol{U} \mathbf{e}\) (assuming unit rewards for simplicity).

\(\mathbb{E}[\tau^2] = 2\cdot\boldsymbol{\alpha} \boldsymbol{U}\boldsymbol{U}\mathbf{e}\)

\(\boldsymbol{U}\mathbf{e} = \boldsymbol{r'} = \triangle\!\,(\boldsymbol{r'}) \mathbf{e}\). So the variance can be written as: \(\mathbb{E}[\tau^2] = 2\cdot\boldsymbol{\alpha} \boldsymbol{U}\!\triangle\!\,(\boldsymbol{r'}) \mathbf{e}\), where \(\boldsymbol{r'}\) are the waiting times computed for the first moment.

Higher-order moments

  • Higher-order moments are the expectation with different rewards.
  • Keep a parameterized list of graph manipulations to avoid redoing the O(V3) expensive conversion to acyclic.
  • Rewards are applied as scalars and do not require recomputation.
  • Additional moments can then be computed in O(V2) time.

Practical Example

Let’s compute properties of an Erlang distribution (sum of exponential random variables):

from phasic import Graph

# Build Erlang(3) distribution: sum of 3 exponentials with rate 1
g = Graph(1)
start = g.starting_vertex()

# Create chain: S -> v1 -> v2 -> v3 -> absorbing
v1 = g.find_or_create_vertex([1])
v2 = g.find_or_create_vertex([2])
v3 = g.find_or_create_vertex([3])

start.add_edge(v1, 1.0)  # Start in state 1 with probability 1
v1.add_edge(v2, 1.0)     # Transition rate 1
v2.add_edge(v3, 1.0)     # Transition rate 1
v3.add_edge(g.find_or_create_vertex([4]), 1.0)  # To absorbing state

# Compute properties
print(f"Expectation: {g.expectation()}")      # Should be 3.0
print(f"Variance: {g.variance()}")            # Should be 3.0
print(f"PDF at t=2.0: {g.pdf(2.0)}")
print(f"CDF at t=2.0: {g.cdf(2.0)}")
